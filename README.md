# Gold Price and Volatility Prediction Using Commodity and Macroeconomic Indicators

Two projects on the same daily dataset of gold, other commodities, currencies,
equity-market data, and macroeconomic series from Yahoo Finance and FRED. Each
folder is self-contained — its own data, notebooks, and `requirements.txt`.

| Folder | Target | Outcome |
|---|---|---|
| [price_prediction/](price_prediction/) | Next day's gold return | Not predictable — R² ≈ 0 |
| [volatility_prediction/](volatility_prediction/) | Gold's realized volatility, 5 and 22 days ahead | Predictable — beats HAR significantly |

The second project exists because of what the first one found. Open either folder
and read its README for the models, results, and how to run them.
